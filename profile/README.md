# RWTH-AVT-SVT

A collection of repositories developed and maintained at RWTH Aachen's Chair for Process Systems Engineering (AVT.SVT).

Repositories are also hosted on the GitLab instance [git.nrw](https://gitlab.git.nrw/rwth-avt-svt).

AVT.SVT is involved in the development of the [Screening Tool for Process Design PAPAYA](https://github.com/Screening-for-Process-Design).
